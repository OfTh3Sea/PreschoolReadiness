# 🌈 Ready for Preschool!

A free, colorful, and interactive web app that helps children ages 1–4 build the skills they need before starting preschool. No downloads, no logins, no accounts, no ads — just pure learning and fun.

## ✨ What's inside

18 fully interactive learning sections covering everything on a standard preschool readiness checklist:

| Category | Sections |
|---|---|
| 📚 **Literacy** | Letters A–Z (uppercase, lowercase, matching game), Letter sounds & phonics, Spell your name, Rhyming |
| 🔢 **Math** | Counting 1–10, Simple addition, Patterns, Big & small comparisons |
| 🌍 **World knowledge** | Colors + interactive color mixer, Shapes, Days of the week, Months of the year, Seasons, Weather, Animal sounds, Body parts |
| 💛 **Social & emotional** | Feelings — 12 emotions with kid-friendly explanations |
| ✍️ **Fine motor** | Letter & number tracing with finger or mouse |

## 🚀 Getting started

### Option 1 — Use it right now
Open the live demo link above. Nothing to install.

### Option 2 — Host it yourself (recommended)

**Netlify Drop** (easiest — 30 seconds):
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag and drop `index.html` onto the page
3. Done — you get a live URL instantly

**GitHub Pages**:
1. Fork this repo
2. Go to Settings → Pages
3. Set source to `main` branch, root folder
4. Your app is live at `https://yourusername.github.io/preschool-readiness`

**Vercel**:
1. Go to [vercel.com/new](https://vercel.com/new)
2. Import this repo or drag and drop the file
3. Deploy

### Option 3 — Run locally
```bash
git clone https://github.com/YOUR_USERNAME/preschool-readiness.git
cd preschool-readiness
open index.html
```

No build step. No `npm install`. No config. Just open the file in any browser.

## 🎮 How it works

Every section has a **Learn** mode and (where appropriate) a **Quiz** mode:

| Mode | What it does |
|---|---|
| **Learn** | Child taps cards, animals, letters, or shapes and hears the name spoken aloud via the browser's built-in text-to-speech |
| **Quiz** | Multiple-choice questions with instant visual and audio feedback, progress dots, and a celebration screen at the end |
| **Interactive** | The color mixer, name spelling game, counting dots, and tracing canvas are hands-on activities |

## 🧠 Preschool readiness checklist

Based on common preschool readiness frameworks:

- [x] Uppercase letter recognition (A–Z)
- [x] Lowercase letter recognition (a–z)
- [x] Letter matching (upper to lower)
- [x] Letter sounds / phonics
- [x] Name recognition and spelling
- [x] Rhyming words
- [x] Number recognition 1–10
- [x] Counting objects 1–10
- [x] Simple addition (sums up to 10)
- [x] AB and ABB pattern recognition
- [x] Color identification (11 colors)
- [x] Interactive color mixing
- [x] Shape identification (8 shapes)
- [x] Days of the week
- [x] Months of the year
- [x] Seasons and weather
- [x] Animal names and sounds
- [x] Body parts
- [x] Emotions and feelings vocabulary
- [x] Size comparisons (big/small, tall/short)
- [x] Fine motor tracing practice

## 🎨 Design

- Soft pastel color palette — bright and cheerful without being harsh
- Animated blob shapes in the background for a playful, living feel
- Rounded everything — no sharp edges, inspired by children's toys
- Spring physics on all interactions — buttons bounce, cards lift, tiles spin
- Each section has its own color identity so children can recognize sections
